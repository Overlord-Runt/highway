# Differential Routing

What the hail is differential routing?????\
That was exactly my reaction when I first heard of it. But when I read into it, I found out hat it is actually pretty cool and very needed.

## So what is this? and why would I need it?

Differential routing is used when you have a pair of high speed data lines such as I2C, usb data lines, or whatever else fits in that definition.

These lines use data pairs that need to travel together and need to be the same length so they arrive at the destination at the same time
